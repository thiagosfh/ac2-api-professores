
# API REST - Gerenciamento de Professores

Projeto acadêmico desenvolvido para a atividade AC2.

## Tecnologias
- Node.js
- Express
- JavaScript
- Postman

## Funcionalidades
- Listar professores
- Buscar professor por ID
- Listar turmas
- Atualizar dados de professores
- Adicionar turmas
- Filtrar por departamento
- Excluir professores

## Como executar

1. Instale o Node.js.
2. Abra o terminal na pasta do projeto.
3. Execute `npm install`.
4. Execute `node server.js`.
5. Acesse `http://localhost:3000/professores`.

Os dados são armazenados em memória e não utilizam banco de dados.
